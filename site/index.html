SYSTEM DESIGN & DEFENSE IN DEPTH

Architecture & Security Specifications

Engineered from the ground up for transparent code modification, permission containment, and zero external trust requirements.

CORE SUBSYSTEMS

Modular Monorepo Architecture

1. Multi-Provider BYOK & Resilient Fallback Engine packages/providers
Unified adapter layer spanning Anthropic, OpenAI, Google Gemini, Groq, DeepSeek, OpenRouter, Mistral, and local Ollama. Dynamic FallbackRouter triggers instant failover on HTTP 429 rate limits, context overflows, or 5xx outages while preserving conversation history and tool execution tokens.
2. Dual-Store SQLite FTS5 Memory Engine packages/memory
High-performance SQLite engine with FTS5 virtual tables and tokenized OR-join queries for sub-millisecond BM25 recall. Paired with Git-trackable Markdown session files in .signhify/ for human auditability and checkpoint restores.
3. Subagent Swarm Orchestrator packages/agents
Decoupled multi-agent execution loop. @planner outputs structured JSON task trees, @editor drafts unified diffs, @reviewer inspects patches against security invariants, and @filepicker executes parallel lookups.
4. Stdio MCP Client & Presets packages/tools
Compliant Model Context Protocol stdio client. Subprocesses spawn strictly via standard I/O streams. Includes pinned preset for REA autonomous software development with full tool approval prompts.
CONTAINMENT SPEC

Zero-Trust Security & Privacy

Zero-Leak Credential Isolation

Plaintext API keys are never written to disk, telemetry traces, or session checkpoint databases. Keys are masked in console output and migrated automatically into native OS keychains (macOS Keychain, Windows Credential Manager, Linux Secret Service).

100% Zero-Telemetry & Sovereign Data

Signhify CLI contains zero analytics trackers, zero usage beacons, and zero prompt logging. Local execution (Ollama, vLLM, LM Studio) operates entirely air-gapped with no outbound network traffic.

Interactive Diff & Execution Gating

File modifications display a unified diff for developer review before touching disk. Plan mode is strictly read-only. Shell execution and MCP tool invocations enforce interactive human approval unless explicitly allowlisted.

Local-Only Stdio Sandbox

All MCP servers and tool subprocesses run exclusively over standard I/O pipes on the local host with sanitized process environments. Untrusted inbound or outbound remote socket execution is blocked.
