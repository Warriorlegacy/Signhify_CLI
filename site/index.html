Engineered for Frontier Developer Experience

A transparent, configurable, local-first coding agent built for real-world software engineering.

🛡️

Resilient Zero-Cost Fallback Chain

Native out-of-the-box priority routing across 9router (port 20128), FreeLLMAPI-Local (port 31415), Antseed, Gemini Studio Free, and OpenRouter Free. Automatically circuit-breaks on 429/402 without burning money.

🧠

Dual-Store SQLite FTS5 Memory

Sub-millisecond semantic retrieval via SQLite FTS5 paired with human-auditable markdown files (.signhify/MEMORY.md and checkpoint.md). Remembers decisions, conventions, and task progress.

🎛️

Split-Pane Terminal UI

Powered by Ink v5. Full split-pane layout matching OpenCode: live conversational chat and diff preview on the left, real-time context token meter, router latency, MCP status, and task tree on the right.

🤖

Specialized Subagent Spawning

Delegates focused tasks to specialized generator-based subagents: @FilePicker (AST scoping), @Planner (task decomposition), @Editor (atomic patching), and @Reviewer (test verification).

⚡

Sliding-Window Context Compaction

Dynamic token monitoring with /context-limit controls. Automatically triggers episodic checkpoints at 80% context utilization, ensuring the model never hallucinates or exceeds token limits.

🔌

Native MCP Client & Presets

Full support for Model Context Protocol (stdio + SSE/HTTP). Pre-configured out of the box for rea (Reverse Engineer Anything), cloudflare, supabase, and openseo.
