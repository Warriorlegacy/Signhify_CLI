# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to [security contact]. Do not open public issues for security vulnerabilities.

## Supported Versions

| Version | Supported |
|---|---|
| 0.x | Yes |

## Security Best Practices

- Never commit secrets or API keys
- Use environment variables for all sensitive configuration
- Rotate credentials immediately if exposed
- Enable 2FA on all GitHub accounts
- Review PRs for security implications before merging
